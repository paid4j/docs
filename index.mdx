## Requirements

- Paper for Minecraft 26.3
- Java 25
- LuaJ 3.0.1 (bundled in the plugin jar)

## Quick example

```lua
cinder.commands.register("hello", {
    execute = function(sender, args)
        sender:sendMessage("Hello from Cinder Lua!")
    end
})
```

Place `.lua` files in `plugins/Cinder/scripts/`, then run `/cinder reload scripts` to load them without restarting the server.

<Warning>
  Scripts run with administrator-level trust. Cinder is not a secure sandbox and does not enforce a script execution-time limit. Only run scripts written by people you trust.
</Warning>
