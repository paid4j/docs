## Requirements

- Paper for Minecraft 26.3.
- Java 25 for Paper and the Gradle build.
- Gradle 9.1 or newer to build from source.

## Build

From the Cinder source project root, run:

```bash
gradle clean test jar
```

The plugin is produced at `build/libs/Cinder-0.1.0.jar`. It bundles LuaJ; Paper API is provided by the server.

## Install

1. Copy `Cinder-0.1.0.jar` into the server's `plugins/` folder.
2. Start or restart Paper 26.3.
3. Confirm the log reports Cinder enabled.
4. Create `plugins/Cinder/scripts/hello.lua`:

```lua
cinder.commands.register("hello", {
    permission = "cinder.hello",
    execute = function(sender, args)
        sender:sendMessage("Hello from Cinder Lua!")
    end
})
```

5. Run `/cinder reload scripts` as an operator or a sender with `cinder.admin`.
6. Grant `cinder.hello` to a player and run `/hello`.

Cinder creates its data folder, default config, and scripts directory at startup. Script files are discovered recursively; only `.lua` files are loaded.

## Manage scripts

```text
/cinder reload scripts
/cinder disable welcome.lua
/cinder enable welcome.lua
/cinder disable /events
/cinder enable /events
/cinder commands
```

Paths are relative to `plugins/Cinder/scripts/`. A Lua filename has no prefix; folder names begin with `/` to distinguish them. Reload reloads all scripts; enable loads only currently disabled files so it does not rerun unrelated loaded scripts.

The management commands require `cinder.admin`, which defaults to operators. See the [Commands](/commands), [Events](/events), and [Tasks](/tasks) guides for APIs.

<Warning>
  Cinder is for trusted administrator-written scripts, not untrusted user code. It has no enforceable execution-time limit.
</Warning>
